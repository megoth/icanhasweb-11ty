# I Can Has Web

The code behind [icanhasweb.net](https://icanhasweb.net/), built using [11ty](https://www.11ty.dev/),
[TypeScript](https://www.typescriptlang.org/), [React](https://react.dev/), [Bulma](https://bulma.io/),
[Markdown](https://en.wikipedia.org/wiki/Markdown), and [MDX](https://mdxjs.com/).

## Scripts

- `npm run build`: Build the HTML
- `npm run dev`: Continuously build and serve the HTML
